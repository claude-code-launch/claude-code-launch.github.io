ccl

A free, open-source command-line tool for software developers that runs Anthropic's Claude Code coding assistant with the model provider of your choice.

This is the official home page of the application ccl, the name shown on its Google sign-in screen. You do not need an account or a sign-in to read this page, download ccl or use it. Signing in with Google is optional and only turns on settings sync (see below).

What ccl does

Claude Code is a coding assistant that runs in a terminal and helps developers read, edit and test source code. ccl starts Claude Code for you and connects it to the model service you choose:

  • Anthropic-compatible API gateways, with your own API key;
  • OpenAI-compatible APIs, by translating requests on your computer through a local proxy bound to 127.0.0.1;
  • coding subscriptions you already have, after you sign in to them.

ccl keeps several saved provider configurations, switches between them, and can connect Claude Code to code editors through the Agent Client Protocol.

ccl is a tool for writing software. It works only with text and source code. It does not create, edit or process images, video or audio.

ccl runs entirely on your own computer. Its developers run no servers, collect no data and have no user accounts. The full source code is public under the MIT License.

Install

npm install -g @claudecodelaunch/ccl   # needs Node.js 22 or later
ccl set                               # add a model provider
ccl                                   # start Claude Code with it

Downloads, documentation and release notes: github.com/claude-code-launch/ccl.

How ccl uses Google user data

ccl uses Google for one optional feature: syncing ccl's own settings between your computers. When you run ccl cloud login and choose Google Drive, ccl opens Google's sign-in page in your browser and asks for one permission:

ScopeWhy ccl needs it
https://www.googleapis.com/auth/drive.appdataTo store one encrypted file, ccl-sync.bundle, in ccl's private application data folder in your Google Drive, and to read it back on your other computers.
  • The file contains only your ccl configuration (provider settings and tokens), encrypted with AES-256-GCM.
  • ccl cannot see, open or change any other file in your Drive, and does not request your name, email address or profile.
  • Google user data is not sent to the ccl developers, to any AI model or to anyone else. It is never used for advertising or to train AI or machine-learning models.
  • ccl does not use Google APIs to generate or process images, and never for AI-generated non-consensual intimate imagery (NCII) or any other sexual content.
  • Delete the synced data with ccl cloud logout --delete-remote --yes. Revoke access with ccl cloud logout --revoke or at myaccount.google.com/permissions.

ccl's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Full details are in the Privacy Policy.

ccl 是一款免费、开源的开发者命令行工具，用来启动 Anthropic 的编程助手 Claude Code，并让它使用你选择的模型服务（Anthropic 兼容网关、OpenAI 兼容 API，或你已有的编程订阅）。ccl 只处理文本与源代码，不生成或处理图片、视频、音频。它完全在你的电脑上运行，开发者没有服务器、不收集数据，也没有账号体系。阅读本页、下载和使用 ccl 都不需要登录。

Google 登录是可选功能，只用于在你自己的多台电脑之间同步 ccl 配置。运行 ccl cloud login 时，ccl 只申请 drive.appdata 权限，在应用专属数据文件夹中保存一个 AES-256-GCM 加密文件 ccl-sync.bundle；它无法访问你 Drive 中的其他文件，也不读取姓名、邮箱。Google 用户数据不会发送给 ccl 开发者、任何 AI 模型或第三方，不用于广告或训练 AI 模型，也绝不用于生成图片或 AI 非自愿亲密影像（NCII）。详见隐私政策与服务条款。
