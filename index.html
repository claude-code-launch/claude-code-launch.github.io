ccl

Claude Code Launch — an open-source launcher and protocol proxy for Claude Code.

ccl runs Anthropic's Claude Code CLI against other model sources: Anthropic-compatible gateways, OpenAI-compatible APIs and several subscription logins. It runs entirely on your own computer; there are no ccl servers or accounts.

Google Drive sync

ccl cloud login can sync your ccl configuration between your own computers through Google Drive. ccl requests only the drive.appdata scope and stores one encrypted file in the app's private application data folder in your Drive. It cannot see your other Drive files and does not request your name or email address. See the Privacy Policy for details.
